# 使用说明与授权

本仓库是独立的 RPG Maker MZ 行走图生成器（单页工具）。

## 代码

仓库内的 `index.html`、样式与脚本由本仓库作者编写，可自由用于个人或商业 RPG 项目。
如需二次分发，请保留本说明。

## 姿势模板

`assets/template.png` 是用户提供的姿势模板（144×192，3 列 × 4 行，48px 单帧），
仅用于规定 RPG Maker MZ 的朝向与脚序。模板不参与最终生成图的颜色。
如你替换模板，请确保你拥有该图片的使用权。

## 内置素体

`bodies/` 里的素体图来自第三方或本项目原创，各自保留原许可，不适用上面的「代码」条款。
作者、来源和许可证见 `bodies/CREDITS.md`：其中 `floursack-chibi.png` 为 CC BY-SA（需署名、改编后同许可共享），
其余为 CC0。

## AI 生成内容

本工具只负责调用你自行配置的 AI 接口。生成图片的版权与使用条件
取决于你使用的模型/服务商条款，本仓库不附带任何模型或素材授权。

## API Key

API Key 只保存在浏览器 localStorage 中，不会写入仓库或导出的工程 JSON。
请勿把带 Key 的截图或配置文件提交到公开仓库。
